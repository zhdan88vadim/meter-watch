## 🔍 **Как это работает - пошагово:**

### 1. **Структура MobileNetV2**

```
MobileNetV2 (предобученный на ImageNet)
├── features (сверточная часть - извлекает признаки)
│   ├── conv1: 3 канала → 32 канала
│   ├── bottleneck блоки (15 штук)
│   └── последний слой: 1280 каналов
├── avgpool (усреднение)
└── classifier (классификатор)
    ├── Dropout(0.2)
    └── Linear(1280 → 1000)  # 1000 классов ImageNet
```

### 2. **Адаптация для 1 канала**

```python
self.backbone.features[0][0] = nn.Conv2d(1, 32, kernel_size=3, stride=2, padding=1, bias=False)
```

**Почему:** MobileNetV2 ожидает RGB (3 канала), а у вас черно-белые (1 канал). Мы заменяем первый сверточный слой, чтобы он принимал 1 канал.

**Что происходит:**
- **Было:** `Conv2d(3, 32, kernel_size=3)` → 3 канала (RGB)
- **Стало:** `Conv2d(1, 32, kernel_size=3)` → 1 канал (grayscale)

**Важно:** Веса нового слоя инициализируются случайно, так как предобученные веса были для 3 каналов.

### 3. **Замена классификатора**

```python
num_features = self.backbone.classifier[1].in_features  # = 1280
```

MobileNetV2 после сверточной части выдает **1280 признаков** (это вектор длины 1280).

**Было (для ImageNet):**
```python
classifier = Sequential(
    Dropout(0.2),
    Linear(1280 → 1000)  # 1000 классов ImageNet
)
```

**Стало (для ваших цифр):**
```python
classifier = Sequential(
    Dropout(0.3),        # ✅ Регуляризация
    Linear(1280 → 512),  # ✅ Сжатие признаков
    BatchNorm1d(512),    # ✅ Нормализация (стабилизирует обучение)
    ReLU(),              # ✅ Активация
    Dropout(0.3),        # ✅ Регуляризация
    Linear(512 → 256),   # ✅ Еще сжатие
    BatchNorm1d(256),    # ✅ Нормализация
    ReLU(),              # ✅ Активация
    Dropout(0.2),        # ✅ Регуляризация
    Linear(256 → 10)     # ✅ Финальный слой (ваши классы)
)
```

## 🎯 **Почему именно так (обоснование):**

### 1. **Почему 512 и 256, а не 128 как в вашей модели?**

```python
# Ваша модель DigitRecognizer
fc1 = Linear(64*7*7 → 128)   # 128 нейронов
fc2 = Linear(128 → 10)

# Новая модель
Linear(1280 → 512)  # Больше нейронов
Linear(512 → 256)   # Больше нейронов
Linear(256 → 10)
```

**Причина:** MobileNet выдает **1280 признаков** (очень много информации). Чтобы не потерять важные признаки, нужен более широкий классификатор.

**Аналогия:** 
- DigitRecognizer: 64*7*7 = 3136 признаков → 128 нейронов
- MobileNet: 1280 признаков → 512 нейронов (пропорционально больше)

### 2. **Почему BatchNorm?**

```python
BatchNorm1d(512)
BatchNorm1d(256)
```

**Причина:** 
- Ускоряет обучение в 2-3 раза
- Делает обучение стабильнее
- Позволяет использовать более высокий learning rate
- Уменьшает переобучение

**Как работает:** Нормализует значения (делает среднее=0, дисперсию=1) внутри каждого батча.

### 3. **Почему Dropout именно 0.3 и 0.2?**

```python
Dropout(0.3)  # 30% нейронов отключается
Dropout(0.3)  # 30% нейронов отключается
Dropout(0.2)  # 20% нейронов отключается
```

**Причина:** 
- MobileNet большой (3.5M параметров)
- Чтобы избежать переобучения, нужна сильная регуляризация
- На последнем слое Dropout меньше (0.2), чтобы не потерять важную информацию

### 4. **Почему такая архитектура именно для цифр?**

```
Изображение 32x32 (1 канал)
    ↓
MobileNetV2 (предобученный) → 1280 признаков
    ↓
Сжатие до 512 (сохраняем главное)
    ↓
BatchNorm + ReLU (ускорение и нелинейность)
    ↓
Сжатие до 256 (еще фильтрация)
    ↓
BatchNorm + ReLU
    ↓
Финальный слой → 10 классов
```

**Почему это работает лучше вашей модели:**

| Аспект | Ваша модель | MobileNet |
|--------|-------------|-----------|
| Предобучен | ❌ Нет | ✅ Да (ImageNet) |
| Количество параметров | ~50K | ~3.5M |
| Признаки | 3136 → 128 | 1280 → 512 → 256 |
| Глубина | 2 сверточных слоя | ~50 слоев |
| Устойчивость | Средняя | Высокая |
